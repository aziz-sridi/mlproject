\section{Introduction}

This report develops predictive machine learning models for global real estate pricing using 147,118 property records. Initial data had 69\% missing values in critical features. An intelligent multi-stage recovery strategy retained 83.2\% of records (vs. 30.6\% with traditional approaches). Three complementary preprocessing pipelines enable flexible model selection: Percentile+Log (normalized features), IQR+Log (robust statistics), and Minimal+Raw (tree-based models). Models are trained, compared, and a champion selected for deployment.

\section{Data Quality and Recovery}

The dataset contained 147,118 records with missing values in area, rooms, and bathrooms. Rather than discarding incomplete records, five recovery stages were applied:

\begin{enumerate}
    \item \textbf{Title Parsing}: Regex extraction from property titles recovered $\sim$112,000 area/room values
    \item \textbf{Duplicate Removal}: Eliminated 342 exact duplicate records
    \item \textbf{Bidirectional Area Estimation}: Used median living-to-total ratio (0.85) to estimate missing areas, recovering $\sim$60,000 values
    \item \textbf{Hierarchical Room Recovery}: Applied country/type/price-tier specific medians for rooms/bathrooms, recovering $\sim$98,000 values  
    \item \textbf{Outlier Removal}: IQR-based capping removed extreme outliers (price: \$0.10--\$15.2M $\rightarrow$ \$2.1K--\$2.1M; area: 5--50,000 m² $\rightarrow$ 42--1,200 m²)
\end{enumerate}

\textbf{Result}: 122,450 clean records (83.2\% retention) vs. only 45,000 complete cases (30.6\%) with traditional methods.

\section{Machine Learning Models}

\subsection{Model Selection Strategy}

Five gradient boosting and ensemble models were trained on each preprocessed dataset:

\begin{itemize}
    \item \textbf{XGBoost}: Regularized gradient boosting with early stopping
    \item \textbf{LightGBM}: Fast, memory-efficient gradient boosting variant
    \item \textbf{CatBoost}: Categorical feature optimized boosting
    \item \textbf{Random Forest}: Ensemble of independent decision trees
    \item \textbf{Gradient Boosting}: sklearn's standard implementation
\end{itemize}

\subsection{Training Framework}

\begin{enumerate}
    \item \textbf{Train/Validation/Test}: 70\% / 10\% / 20\% stratified split by price tier
    \item \textbf{One-Hot Encoding}: Categorical features (country, property type) encoded for tree compatibility
    \item \textbf{Hyperparameter Tuning}: Each model optimized for validation RMSE
    \item \textbf{Evaluation Metrics}: 
    \begin{itemize}
        \item MAE (Mean Absolute Error): Interpretable error in original currency
        \item RMSE (Root Mean Square Error): Standard metric penalizing large errors
        \item $R^2$ Score: Fraction of variance explained
    \end{itemize}
\end{enumerate}

\subsection{Model Selection Procedure}

\begin{enumerate}
    \item For each of 3 preprocessing approaches, train 5 models and select best by validation RMSE
    \item Compare 3 approach-specific winners across test set performance
    \item Choose overall champion with lowest test RMSE
    \item Save champion model for deployment
\end{enumerate}
